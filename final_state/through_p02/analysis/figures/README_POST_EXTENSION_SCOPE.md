# P02 figure scope after the 64/128/256 extension

The PNG figures in this directory are preserved pre-extension presentation assets from the original finalized P02 package. No replacement PNG figure set was supplied by the extension delta, so these figures are intentionally retained rather than fabricated or silently altered.

For the current 1→256 low-label numerical state and repeated Stage18S extension, use the current CSV/JSON sources in `../table_source_data/p02/`, `../P02_64_128_256_Extension_Addendum_R1.md`, and `../../extension_annex/`.

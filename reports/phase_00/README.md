# Current Phase 0 reports

This directory retains the compact, downstream-useful current report surface.

- `current_handoffs/` contains current machine-readable handoffs.
- `current_manifests/` contains responsibility, layer, expected-output, ablation, document, Evidence Map, and Layer 10 records.
- `final_audit_summaries/` contains concise current summaries rather than raw pass logs.

The complete internal history and raw audit evidence remain in the separate R5 release-assets package.

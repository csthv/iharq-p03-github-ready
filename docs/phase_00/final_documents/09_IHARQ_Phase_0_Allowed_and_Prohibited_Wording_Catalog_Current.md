# IHARQ Phase 0 Allowed and Prohibited Wording Catalog R1

## P00-CLM-001 v1

**Allowed wording:** Under the exact registered local snapshot and verified Python 3.13.5 environment, all 19 registered Phase 0 engineering/foundation conformance cells passed; this is non-empirical Mode B evidence and does not establish scientific effectiveness or Phase 0 closure.

**Required qualifiers:** exact local snapshot, Python 3.13.5, Mode B engineering/retrospective, non-empirical P00, Phase 0 not closed.

**Required warnings:** Do not generalize beyond the frozen snapshot and environment.

**Prohibited wording:** All system phases passed.; The system is scientifically validated.; Phase 0 is closed..

## P00-CLM-002 v1

**Allowed wording:** In the frozen local Python 3.13.5 environment, the complete registered deterministic suite passed 102 of 102 tests; cross-version portability is not established.

**Required qualifiers:** frozen local environment, 102-test registered inventory, no cross-version portability claim.

**Required warnings:** Python 3.11 and 3.12 were not verified.; Portable uv.lock remains incomplete and fail-closed.

**Prohibited wording:** The suite passes on all supported Python versions.; The package is universally reproducible..

## P00-CLM-003 v1

**Allowed wording:** Within the registered non-empirical fixture inventory, all 19 valid or integrated bundles were accepted and all 178 intentionally malformed categories were rejected as expected, with zero false valid rejections and zero false malformed acceptances.

**Required qualifiers:** registered fixture inventory only, non-empirical fixtures, expected malformed rejection counts as validator success.

**Required warnings:** This does not cover every possible malformed input or establish scientific performance.

**Prohibited wording:** The validator rejects all possible invalid data.; The system is empirically robust..

## P00-CLM-004 v1

**Allowed wording:** The frozen Phase 0 package contains and validates the registered foundation inventories of 85 schemas, 35 configuration profiles, and 79 record-family profiles; inventory closure does not establish later-phase scientific effectiveness.

**Required qualifiers:** registered Phase 0 inventory, presence plus validation, foundation scope only.

**Required warnings:** Do not interpret catalog closure as empirical validation of downstream behavior.

**Prohibited wording:** All scientific artifacts are complete.; The complete system is validated..

## P00-CLM-005 v1

**Allowed wording:** All eleven Layer 0–10 foundation interfaces passed the registered Phase 0 integration scope; no later-phase scientific execution or effectiveness result is claimed.

**Required qualifiers:** foundation interfaces, registered P00 integration scope, no later-phase execution.

**Required warnings:** Layer foundation completeness is not complete scientific implementation of each layer.

**Prohibited wording:** All layers are scientifically complete.; Layer 10 final project package is complete..

## P00-CLM-006 v1

**Allowed wording:** The P00 implementation foundation is complete within its registered local scope, and P01–P15 reusable contract surfaces are ready for later governed annex creation and execution; future empirical outputs have not been produced.

**Required qualifiers:** P00 local implementation scope, P01–P15 contract surfaces only, future outputs not executed.

**Required warnings:** Contract readiness is not phase execution or result readiness.

**Prohibited wording:** P01–P15 are complete.; All later phases are ready for deployment..

## P00-CLM-007 v1

**Allowed wording:** The package reproduced from a clean isolated copy under the exact verified Python 3.13.5 and 22-distribution local dependency snapshot; portable cross-version reproducibility is not established.

**Required qualifiers:** clean isolated local copy, Python 3.13.5, exact 22-distribution snapshot, local reproducibility only.

**Required warnings:** Portable uv.lock is incomplete.; Python 3.11 and 3.12 remain unverified.

**Prohibited wording:** Universally reproducible.; Cross-platform verified.; Reproduces on Python 3.11–3.13..

# Publication-facing repository selection

This directory records the current public-facing file selection boundary for the cumulative GitHub-ready repository through P02. It does not approve scientific claims; reviewed wording and evidence eligibility remain controlled by Layer 0 and the cumulative Evidence Map under `final_state/through_p02/`.

Final GitHub publication timing remains a project-level governance decision. This manifest exists so publication/export tooling has an explicit, current file-selection surface rather than relying on the historical P00 manifest.

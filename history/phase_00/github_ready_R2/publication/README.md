# Local scholarship publication build

This directory records the source-to-publication selection and validation for the local R2 package. No GitHub repository was connected, inspected, or modified.

- `file_selection_manifest.csv` / `.yaml`: disposition of every R5 source path;
- `local_build_report.md`: local build and validation summary.

The external delivery also includes the full publication manifest, source crosswalk, validation report, replacement guide, PR description, release notes, handoff, and comprehensive Word/Markdown reports.
